# AURA Wellness Studio — бриф и архитектура

## Цель

Стабильный красивый Telegram business bot для демонстрационного бизнеса
AURA Wellness Studio. Готов к реальному деплою на Cloudflare Workers.

## Стек

- TypeScript, Cloudflare Workers, Telegram Bot API напрямую через fetch.
- Webhook endpoint `/webhook`, без long polling.
- Состояние пользователей — Cloudflare KV (binding `BOT_STATE`, TTL 24 ч).
- Без тяжёлых Node.js Telegram-фреймворков, без Google Sheets / CRM / платежей / внешней БД.

## Функции

- `/start` с приветствием и главным inline-меню (7 пунктов).
- Услуги: 4 категории, 9 услуг с описанием, длительностью, ценой и кнопкой записи.
- Специалисты: 3 человека + вариант «любой свободный».
- Booking flow: услуга → специалист → дата (5 дней) → время (5 слотов) →
  имя → телефон → проверка → подтверждение.
- После подтверждения: карточка записи клиенту + уведомление в ADMIN_CHAT_ID.
- FAQ (5 вопросов), акции (2), отзывы (4 демо + сбор новых).
- Связь с администратором (пересылка + данные отправителя).
- Временная команда `/chatid` (удаляется после настройки, блок помечен TEMP).
